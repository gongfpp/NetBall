一、真正“悬浮置顶”的

NetWorx · 浮动应用列表 最像加速球

独立小窗常驻桌面：每个 App 的上传 / 下载实时速率。Windows 是这套 UI，macOS 版同样有浮动图表 + 应用列表。

NetWorx · 浮动图表

同一窗口的图表视图，底部显示当前总上传 / 下载。可在菜单里切换。

GlassWire · mini viewer

小图钉在屏幕上（截图里叠在全屏视频上），按网络分别显示 ↓/↑。Windows / Android，有免费版。

TrafficMonitor · 悬浮窗（免费开源）

右键菜单里就是你要的那几项：总是置顶 / 鼠标穿透 / 锁定窗口位置 / 不透明度。但只有总网速 + CPU/内存，没有进程流量排行。

二、macOS：菜单栏 + 每进程明细

iNTM · 菜单栏 + 弹出面板 macOS 首选

菜单栏直接显示 1.37 KB/s / 365 B/s，点开就是 Upload / Download + Programs 列表（图里是 WeChat.app 的实时速率）。需要 macOS 15+。

iNTM · 主面板

总速率、Wi-Fi 信号、公网/内网 IP、进程列表、3 分钟曲线；另有历史统计、连接列表、按 App 防火墙。

iNTM · 流量历史

按 App 和时间段聚合，能回答“这个月谁把我的流量吃完了”。

Little Snitch · 网络监视器

左侧按 App 列流量条 + 右侧世界地图连线，底部 sent/received 汇总。偏安全审计，付费。

Netiquette · 免费开源

按进程展开 socket，带 Bytes Up / Bytes Down 和可执行文件路径。注意：这是累计字节，不是实时速率，也没有置顶悬浮。

Stats · 免费开源菜单栏

CPU/GPU/内存/网络/磁盘/传感器一整套。网络模块以总量与曲线为主，进程排行不是它的强项。

三、Windows：进程级排行

NetLimiter · 每进程 DL/UL 速率

Activity 列表直接按进程给 DL Rate / UL Rate，右侧可加限速/阻断规则，还有 Traffic chart。

NetWorx · 增强 netstat

进程 + 协议 + 本地/远端地址 + 状态 + Upload/Download，可按进程名过滤。

四、最后做出来的东西（NetBall）

菜单栏图标（默认模式）最终形态

上下两行 ↓/↑ 实时速率，29×18pt，比横排窄约 2/3；深色/浅色菜单栏都适配。点图标出菜单。

悬浮球模式（可选）

无边框置顶小球，显示总上下行；单击展开面板。收起态实测 12 MB / 0.9% CPU。

展开面板：总量曲线 + 进程 Top 5

数据源 nettop 单发快照差分（免 sudo），展开时自动切到 1 秒采样，收起回到 2 秒。

真实流量（程序自渲染，非截屏）

verge-mihomo / node / Tailscale 等真实进程在榜，37 个进程参与统计。
